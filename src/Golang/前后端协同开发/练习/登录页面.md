## 项目初始化
### 配置Daisy UI
配的时候发现怎么配都不行，发现原来是TailwindV4太新，Daisy UI没更上……
![](assets/Pasted%20image%2020251125225418.png)
*一部分报错日志*
![](assets/Pasted%20image%2020251125230040.png)
*Stack Overflow上的相关帖子*

先暂时退回到Tailwindv3吧
```sh
npm install -D tailwindcss@v3 postcss autoprefixer
npx tailwindcss init
```

然后补上文件：
- `src/app.css`：
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```
- `tailwind.config.js`：
```js
/** @type {import('tailwindcss').Config} */
export default {
  // 1. 扫描所有 svelte 文件
  content: ['./src/**/*.{html,js,svelte,ts}'],
  theme: {
    extend: {},
  },
  // 2. 加载 daisyui 插件
  plugins: [
    require('daisyui'),
  ],
  // 3. (可选) 配置 daisyui 主题
  daisyui: {
    themes: ["light", "dark", "cupcake"],
  },
}
```
